How to use this page

  1. This page loads data/cafes.json from the site and lists every café. Search the table, or press Add a café.
  2. Press Edit or Delete on any café. Your changes stay in this browser tab only: nothing is saved online, and closing or reloading the tab loses them.
  3. When you're done, press Download cafes.json. Put the downloaded file in the project's data folder in place of the old cafes.json, then deploy the site as usual.

Anyone who finds this page can open it, but it can't change the live site: only the file you put in the project does. It isn't linked from the site, and search engines are asked not to list it.
